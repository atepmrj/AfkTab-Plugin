# AfkTab (Spigot 1.21.11)

Помечает AFK игроков и ботов в табе (`[AFK] Ник`, серым), опускает их вниз списка
и показывает реальный онлайн в футере таба.

- AFK определяется ТОЛЬКО по ходьбе (перемещению). Чат, клики, инвентарь, поворот головы не считаются.
- Статус и накопленное время бездействия сохраняются при выходе (файл data.yml),
  поэтому после перезахода бот, который стоит, снова сразу получает AFK, а снимается метка только когда он пойдёт.

## Сборка
Нужны JDK 21 и Maven:

    mvn clean package

Готовый файл: `target/AfkTab-1.0.0.jar` -> положить в папку `plugins/` сервера.

## Команды и права
- `/afk` - включить/выключить AFK вручную (`afktab.use`, по умолчанию у всех)
- `/afktab reload` - перезагрузить конфиг (`afktab.admin`, по умолчанию op)
- `afktab.exempt` - игрок никогда не получает AFK автоматически

Все настройки в `plugins/AfkTab/config.yml`.
